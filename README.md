
# Configuración de la Cuenta de Azure

## 1. Plataforma Seleccionada
Para la realización de esta práctica se seleccionó la plataforma **Microsoft Azure** utilizando el servicio **Azure App Service (Windows)**.

## 2. Creación y Configuración de la Cuenta

1. Se accedió al portal oficial de [Azure Portal](https://portal.azure.com/) e inició sesión con la cuenta institucional
2. Se verificó el acceso al panel de administración y se validó la disponibilidad de recursos en la suscripción *Azure for Students*.
3. Se creó un Grupo de Recursos denominado `rg-proyecto-rs` para alojar los servicios del laboratorio.
